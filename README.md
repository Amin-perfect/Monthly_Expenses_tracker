# Monthly Expense Tracker

A simple desktop Monthly Expense Tracker made with Python + Tkinter + SQLite.

## Features
- Simple modern desktop UI
- Add expenses with date, category, description and amount
- PKR currency
- Monthly filtering using YYYY-MM
- Monthly total, expense count and average
- Delete selected expense
- SQLite database automatically created as `expenses.db`
- Emoji icons for categories and dashboard cards
- No external Python packages required

## Run
```bash
python expense_tracker.py
```

Python 3.9+ recommended.
